# Bài tập Java - TUAN1 đến TUAN15 (trừ TUAN7)

Cấu trúc có 14 tuần: `TUAN1`–`TUAN6`, `TUAN8`–`TUAN15`.

Trong mỗi tuần có **hai thư mục rỗng**:
- `LyThuyet`: để bạn tự thêm tệp `.java` phần lý thuyết.
- `Baitap`: để bạn tự thêm tệp `.java` phần bài tập.

Các thư mục nằm trong `src/main/java/` để IntelliJ IDEA nhận dạng là mã nguồn Java.

## Mở trong IntelliJ IDEA
1. Giải nén file ZIP.
2. Vào **File → Open** và chọn thư mục **Java_TUAN1_TUAN15** (thư mục chứa `pom.xml`).
3. Nếu IntelliJ hỏi có muốn mở dưới dạng **Maven project**, hãy đồng ý.
4. Vào `src/main/java/TUAN1/Baitap`, chọn **New → Java Class** rồi đặt tên, ví dụ `Bai1`.

Nếu IntelliJ báo thiếu JDK, vào **File → Project Structure → Project SDK** để chọn hoặc cài JDK 17 trở lên.

**Ghi chú:** Thư mục hiện đang để trống, chưa có mã Java mẫu để bạn tự thêm bài học theo ý mình.
